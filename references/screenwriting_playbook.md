# 短剧编剧手册（写剧本的固定流程）

> 🔴 **为什么有这份文档**（2026-10-24，ep05 用户反馈「情节不顺畅、编剧还是有问题」）：
>
> ep05 之前，每一集的镜头表都是**在会话里现写 Python 脚本**直接生成的
> （`tools/make_ep03.py` / `make_ep04.py` / `make_ep05.py`）。
> 这意味着 **skill 里那套编剧规则（logline 四要素、情绪曲线、母题回环、因果链）
> 从来没生效过**——因为它根本没经过 `story` 流程，是绕过去的。
> 结果就是：**每集编剧水平全看当场发挥，所以每集都不一样，有的集情节硬伤明显。**
>
> **本手册就是把那套「靠发挥」的东西变成「有固定流程」。**

---

## 零、铁律（违反就返工）

| # | 铁律 | 为什么 |
|---|---|---|
| 1 | **不许直接写分镜，先立骨架** | 直接写分镜 = 用意象填空，必然散 |
| 2 | **骨架没写完不许动 `shot()`** | 22 镜写完再发现逻辑断，重写成本极高 |
| 3 | **每一镜都要填满四个空** | 填不出「因为上一镜…」= 这镜是废镜 |
| 4 | **写完必须跑 `ac.py check`，有「必须改」不许往下走** | 十段视频跑八十分钟，剧本错一句全废 |
| 5 | **剧本只能由 `tools/gen_story.py` 从 shots.json 生成，不许手写** | 手写的剧本会和镜头表对不上（ep05 就出过这问题） |
| 6 | **交付前必须跑 `tools/deliver.py`** | 它会重生成剧本 + 跑自检 + 同步交付物 |

## 一、Step 1：写「剧本工单」（六行，不许空）

**这是最重要的一步。** 不填这六行就写分镜 = 意象填空。

```text
我想让观众感觉到：______（一种情绪，如「解气」「被理解」「香」）
主角想要：______
他的阻碍：______
最后他明白了/变成了：______
必须出现的画面：______（最多 3 个，多了就散）
绝对不能出现的：______
```

> **AI 的自由度只在「怎么拍」，不在「拍什么」。**
> 这一步定的是「拍什么」——所以必须人来定，或者用户给。

### 1·五 logline 四要素

```
谁 + 想要什么 + 遇到什么阻碍 + 最后变成什么
```

- ❌「一个猫去乡下野炊做折耳根」——只有做什么
- ✅「猫哥想在乡下给朋友们露一手做折耳根，结果挖了老乡的地被讹钱，
  最后用一盘菜把讹人的人变成了常客」——有欲望、阻碍、变化

**logline 定不下来，后面 22 镜一定散。**

## 二、Step 2：定三张表（写分镜之前）

### 2.1 情绪曲线表

每镜一个 `intensity`（-5 ~ +5），先排完再写镜头。

| 规则 | 说明 |
|---|---|
| 至少一个**最低点** | 转折的起点，通常在 60%-75% 处（太早没铺垫，太晚没戏） |
| 至少一个**最高点** | 情绪释放，一般在最后 1-2 镜 |
| 禁止连续三镜同值 | 否则「一直平」 |
| 末镜接近全片最高 | 结尾不能淡收 |
| **锯齿型 > 平推型** | 真实的烹饪/干活节奏本来就有起伏，一路平推反而假 |

### 2.2 母题表（motif）

一个**具体物件或动作**贯穿全片：首镜出现、末镜回应。

| 类型 | 例子 |
|---|---|
| 物件 | 一把带泥的折耳根（开头在坡上，结尾夹进老汉的碗里） |
| 动作 | 猫哥的手（开头翻草丛，结尾给别人盛饭） |
| 一句话 | 开头说一半，结尾说完 |

观众不一定注意得到，但会**感觉到完整**。

### 2.3 出场表

| 角色 | 功能定位 | 首次出场镜 | 必有名词/动作 |
|---|---|---|---|
| 猫哥 | 主角 | S01 | — |
| 老乡 | 冲突方 | S15 | 「谁让你们挖的！赔钱！」 |
| 祥婶 | 内部人拆台 | S18 | 「你晓不晓得根本没人要！」 |

🔴 **每个角色都要填「必有名词/动作」**——
填不出来的角色要么给他一句台词，要么让他别出现（纯凑人数的会被模型画丢）。

## 三、Step 3：写镜头（每镜必填四空）

写任何一镜之前，先填这四个空：

1. **这一镜的作用**：推进 / 停顿 / 转折（三选一，不允许「没有作用」）
2. **因为上一镜 ______，所以这一镜 ______**
3. **他在这里做什么**：必须是一个**动作**，不能是「站着看」
4. **观众看完应该想**：______

> 第 2 条是杀废镜的刀：**填不出来就说明这镜该删**。

---

## 四、Step 4：结构硬伤自查（ep05 教训，必做）

这四类是「逐镜看都通、连起来看莫名其妙」的伤，`ac.py check` v1.19.0 已能自动查，
但**你得先自己写对**，检查器是兜底不是主力。

### 4.1 问句和答句必须是同一个问题

问价格 → 答好不好吃 = 没答。**被问的人全程没答那句问，观众会一直等着听答案。**

修法：同一句里先答后转——「三毛一斤，您尝尝，值不值这个价。」

### 4.2 冲突方不能天降

反派第一次出现前，必须交代过他的存在或来由。**最有效的是画面线索**：
坡边的旧界碑、围栏、标牌——主角经过时没当回事，观众看到了记住了，
后面他从这个方向出现就顺理成章。

🔴 画面线索要**写进 `frame.prompt`**，光写在 `because` 里观众看不见。

### 4.3 人跑了就别再莫名回来

离场镜之后两镜内必须有「回来」的交代。**优先用喜剧小插曲 + 下一镜明确交代**，
这样既保住了节奏，又不用删镜。

### 4.4 每一镜都要能被删掉测试

随机删掉一镜，故事照样成立 → 废镜。
过场镜（「赶到河边」「大家开始收拾」）最容易被写成风景介绍，重点查。

## 五、Step 5：写完必跑

```bash
# 1) 逻辑自检（有问题不许往下走）
python "<skill目录>/scripts/ac.py" check ep05

# 2) 生成剧本（从 shots.json 推导，绝不手写）
python tools/gen_story.py ep05

# 3) 交付收尾（重生成剧本 + 自检 + 同步交付物）
python tools/deliver.py ep05
```

## 六、「每集都不一样」怎么根治

ep05 之前的坏做法：

```
❌ 在会话里现写 make_epXX.py → 直接生成 22 镜 → 跑视频
        ↑ 跳过骨架、跳过 story 流程、跳过编剧规则
```

正确的做法：

```
✅ Step 1 写工单（六行）
   Step 2 定三张表（情绪曲线 / 母题 / 出场表）
   Step 3 逐镜填四空
   Step 4 结构硬伤自查
   Step 5 check → gen_story → 出片 → deliver
```

**每一集都走同一条流程**，质量就稳定了——这是「不靠每次发挥」的唯一办法。

## 七、常见坏味道（写的时候自查）

| 坏味道 | 观众感受 | 怎么改 |
|---|---|---|
| 每镜之间接不上 | 「她怎么又到这儿了？」 | 补「因为上一镜…所以…」 |
| 冲突来得太突然 | 「这谁啊？」 | 提前一镜埋界碑/标牌/台词 |
| 问了没人答 | 「他问的啥？后面呢？」 | 答句必须覆盖问句话题 |
| 跑了又回来 | 「什么情况？」 | 下一镜交代「请回来」 |
| 都在「站着看」 | 「像换装展示」 | 每镜一个具体动作 |
| 台词念不顺 | 「这人在念说明书」 | 台词口语化、有潜台词、≤18 字 |
| 短句单独占一镜 | 「空了两秒」 | 并进相邻镜 |
| 结尾两人站着说完 | 「所以呢？」 | 结尾必须是肢体动作 |
