---
description: 从一句话创意开始做一条 Agnes Clip 短剧（自动建项目、写剧本、生图出视频）
argument-hint: "<一句话创意> [可选：项目目录]"
---

用本 skill 的 `ac.py`（`~/.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py` 或项目 `.workbuddy/skills/` 下的同名文件），Python 3.13.12。

**创意是**：「$ARGUMENTS」

按这个顺序走，每一步做完先验收再进下一步（别一口气 `auto` 冲到底）：

1. **先问清楚 3 件事**（一次问完，别来回追问）：
   - 片子要多少秒？（竖屏短剧一般 90–150 秒）
   - 主要人物几个？大概什么年龄、什么身份？
   - 结尾想要什么感觉？（催泪 / 反转 / 爽 / 悬疑）
   加上「出图通道」要先定：跑 `pick-image` 给项目选通道（agnes / gpt-image / openai）。

2. **建项目 + 写剧本**：
   ```
   <ac.py路径> init "<项目目录>" --title "<片名>" --duration <秒>
   ```
   然后自己写 `script/story.md` 和 `script/shots.json`（**这一步必须手写，不要让脚本自动生成敷衍版**）。
   剧本硬要求：logline 四要素、情绪曲线有高低点（不能一路平）、母题首尾回环、至少做一次「删掉一镜看会不会塌」的测试。
   详细字段看 skill 的 `references/shot_schema.md` 和 `references/screenplay.md`。

3. **角色定妆图**：
   ```
   <ac.py路径> char-gen "<项目目录>" --name <名字> --desc "<外貌+年龄+服装+气质>"
   ```
   生成后**必须打开图片亲眼看**：脸像不像人设、年龄对不对、几个角色会不会撞脸。不合格就改描述重出。

4. **道具图**（只建近景会被看清的，母题道具必须在）：
   ```
   <ac.py路径> prop-gen "<项目目录>" --name <道具名> --desc "<描述>"
   ```

5. **场景板**（场景 × 机位，同一场景各机位必须共用同一份陈设清单，只换机位不换布景）：
   ```
   <ac.py路径> scene-gen "<项目目录>"
   ```
   生成后逐张验收：是不是同一个地方、墙和家具对不对、有没有多余道具。

6. **首帧**（先 `--dry-run` 看提示词，再真出）：
   ```
   <ac.py路径> frame "<项目目录>" --dry-run
   <ac.py路径> frame "<项目目录>"
   ```
   四个硬保证，逐张核对：锁人脸、带上参考图、人数锁死、人物左右位置不变。
   **一定要亲眼看图**，别只看日志说「完成」。

7. **视频**（3 路并发，Agnes 账号限流 30 秒一次，别加太多并发）：
   ```
   <ac.py路径> video "<项目目录>" --wait
   ```
   段数必须等于镜头数。失败的单跑：`<ac.py路径> video "<项目目录>" --only S07 --wait`

8. **质检**：逐镜抽 3 帧 + 抽音轨转写，确认每句台词真的念出来了、没穿帮、没跳轴。

9. **精修**（这一步不能省）：配乐（`music` → `music-ui` 逐镜调音量）、音效（真素材，不要用 TTS 拼）、转场（`shot.x`）、逐句字幕（`shot.subs`）。
10. **合成 + 验收**：
   ```
   <ac.py路径> assemble "<项目目录>" --subs --voice
   <ac.py路径> audit "<项目目录>"
   ```

11. **交付**：成片复制到 `out/<片名>.mp4`，清掉 `_p_*`、`qa/`、`_test_*` 临时文件。

每一步做完都跟用户报进度（哪些产物、在哪、有没有需要人眼验收的）。完整手册看 skill 的 `references/full_pipeline.md`。
