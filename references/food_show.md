# 美食号套路（food_show）

> 用在「以做饭/出菜为主线」的集。ep04《后厨风云》就是按这套写的，可直接复用。

## 一、核心差异：不是剧情片，是「让观众看完想吃东西」

| | 剧情片（ep03） | 美食号（ep04+） |
|---|---|---|
| 时长 | 50-60s | **115-130s**（用户明确要求「120 秒左右」） |
| 镜头数 | 12-13 | **20-24** |
| 主体 | 角色对话推动 | **炒菜段占 30-45 秒纯画面** |
| 台词密度 | 每镜都有 | 炒菜段**一句台词都没有**，全靠动作和声音 |
| 结尾 | 情绪缓和一个拥抱 | **必须「看得爽」**：征服顾客 / 被老婆夸 / 端上桌的瞬间 |

关键认知：**炒菜段没有台词不是缺点，是特色。** 那30 多秒是观众「看饿了」的地方，
一旦塞进对话，观众分心去听词，就尝不到香味。声音要顶上去（见 §四）。

## 二、22镜的标准骨架

```
S01-S03钩子（3秒抓人）      冲突/难题摆在眼前，3 秒内必须出现「他要做什么」
S04-S05  交代（低潮）        让观众看到「不这么做就完了」，压力落地
S06-S11🔥 炒菜段（30-45 秒，无台词）  ← 本集的命根子，见 §三
S12      喜剧缓冲（可选）    惯偷/冒失角色喘口气，别让观众一直紧张
S13      反派上门（谷底）    全片最低点，压到 -4
S14      主角忍住了（停顿）  火气压下去。动手就low 了，手艺人靠手艺赢
S15-S17  让菜说话            端盘 → 反派动筷 → 反派认输（全程不吵架）
S18-S21  街坊回流+情绪收束    客人自己回来、猫嫂尝菜、街坊鼓掌、主角独处卸力
S22      结尾高潮             被老婆当众夸 / 征服全场，intensity = +5
```

情绪曲线（照抄即可）：

```
 0 → -2 → +1 → -3 → +1 → 炒菜段爬到 +4 → -1 → -4 → -1 → +1 → +3 → +4 → +3 → +2 → +3 → +2 → +5
        ↑钩子            ↑手活        ↑谷底↑靠菜赢           ↑回流          ↑结尾
```

## 二·五、因果链的两条铁律（用户两次指出过的地方）

> 用户原话：「怎么从前面突然就说要做一般给你看啊，你要检查一下逻辑，要连贯一点儿，
> 要看观众看着明白意思，又过瘾」

**铁律一：反派必须先踩手艺，主角接战才有理由。**

只压价、不踩手艺 → 主角那句「我跟你干」就是凭空来的，观众会问「做给谁看？」

- 反例：狼兄说「这价我说了算」（纯压价）→ 猫哥下一镜就说「那我做一盘给你看」——**没有靶子**
- 正例：狼兄说「一块五，爱卖不卖。你那豆角子，配叫镇店菜？」
  → 猫哥「就配。这半筐豆角，我照样炒一盘。」
  ——**被激到了才接战**，而且「就配」两个字把挑衅顶了回去

**铁律二：反派上门必须有来由，不能天降。**

「他没尝过就来说菜一般」是硬伤。

- 正例：猫哥在菜市场当众承诺「我照样炒一盘」，这句话传到狼兄耳朵里，
  所以他是**来验收承诺的**——进门先闻到香味，然后说「哟，还真炒上了？我可等着呢。」
  这一句同时解释了「他为什么来」和「他凭什么等着」
- 反例：狼兄踹门进来就说「就这？也就一般吧」——他尝都没尝过凭什么评价

**附带收获**：把「豆角被截了」改成「**就剩这半筐豆角**」，一举解决两件事——
接战的赌注有了（半筐菜背水一战），S04 客人为什么走也有了（菜价被定死，吃不起）。

> 改逻辑时顺手把**道具的来路交代清楚**，比事后解释省力得多。

**自查办法**：把每镜的台词连起来念一遍（`ac.py check` 会顺便查问答闭环）。
念到某句需要「为什么」才接得上，那里就是断的。

## 三、炒菜段的六个招牌动作（用户点名要的）

每个动作单独占一镜（5-9 秒），**无台词**，机位要换。ep04 的 S06-S11 就是这六个：

| # | 动作 | 时长 | 怎么写提示词 | 声音 |
|---|---|---|---|---|
| 1 | **备菜**（掐头去蒂） | 6s | 「双手拇指一掐，咔咔两声，断口齐刷刷排成一列」 | `chop` 密集节奏 |
| 2 | **切菜**（刀工） | 7s | 「刀起刀落，刀背敲下案板清声」+ 刀必须写「厚背菜刀 worn grey steel blade + 木柄」 | `chop` + `clang` |
| 3 | **扔刀**（招牌） | 6s | 「手腕一抖抛起，刀在空中翻个身，半空一把接住，顺手插回刀架」+ **全程眼睛盯案板不追刀** | `whoosh` + `clang` |
| 4 | **热锅下油→下料→ 颠勺** | 8s | 「蓝火窜起一尺高，油沿锅边淋进去；一把扫进锅，油滋啦炸开，连抖三下」 | `flame` + `sizzle` + `woktoss`×3 |
| 5 | **翻锅**（大颠勺，最爽） | 5-6s | 「换左手抓勺右手托锅，整锅翻起来，火苗顺锅沿窜上半尺，豆角空中翻身落回」 | `whoosh` + `sizzle` |
| 6 | **收汁→ 妥菜**（最见功力） | 9s | 「淋一圈料汁，勺子贴锅底推，汁水一遍遍裹上去，颜色变油亮；手腕一抖甩进白瓷盘，擦掉盘边一滴汁」 | `sizzle` + `plate` + `clang` |

**写这些动作的三条硬规矩**：

1. **道具必须写材质和尺寸**。写「菜刀」模型会画塑料玩具；写
   `a heavy thick-bladed Chinese cleaver with a worn grey steel blade and a wooden handle` 才对。
2. **手上功夫镜不给台词**。低机位特写里嘴不清楚，配了音对口型反而不自然；这类镜让声音说话。
3. **同框身体 ≤ 2**。炒菜段只有猫哥一人；狗老弟/兔子妹妹在旁边看的话单独给一镜，否则前景那个会丢。

## 四、声音是美食号的另一半

炒菜段的音效比画面还重要。已内置 7 个厨房音效（`scripts/sfx.py`）：

| kind | 声音 | 用在哪 |
|---|---|---|
| `chop` | 刀剁案板 | 切菜、剁馅 |
| `clang` | 厚背刀敲案板清声 | 刀工收尾、扔刀接住 |
| `sizzle` | 油爆「滋啦」 | 下豆角那一声（**本集第一口，音量给足**） |
| `woktoss` | 颠勺（气流 + 金属回响） | 每次颠勺 |
| `flame` | 灶火呼呼 | 热锅垫底 |
| `plate` | 瓷盘上桌清脆叮 | 妥菜那一下 |
| `paper` | 撕纸 | 反派撕菜票 |

用法（音量别都压-12，**第一口要突出**）：

```python
sfx=[{"kind": "sizzle",  "at": 3.0, "gain_db": -8},   # 下锅，最响
     {"kind": "woktoss", "at": 4.2, "gain_db": -9},
     {"kind": "woktoss", "at": 5.2, "gain_db": -9},
     {"kind": "flame",   "at": 1.0, "gain_db": -14}]  # 灶火，垫底
```

## 五、结尾两种收法（用户给了二选一）

**A. 征服型（打服反派）**

```
S15 端盘（不说话）→ S16 反派动筷（**全程无台词**，只靠表情）→ S17 反派低头认输
```
铁律：**反派不能动手**。美食号的规矩是手艺人靠手艺赢，一打架就low 了。
反派认输的信号是「耳朵耷拉+ 肩膀垮了 + 把盘子推回去」，不是「被打服」。

**B. 被夸型（本集用的这个）**

```
S19 老婆尝菜（震惊到说不出话）→ S20 街坊鼓掌 → S21 主角独处卸力 → S22 老婆当众夸
```
末镜 `ending_mode = "bow_apology"`。台词要点：**「我老公这手艺，够吃一辈子。」**
—— 具体、有归属感（叫「我老公」不是「你」）、把夸奖说给全店人听。
配套动作：把围裙披他肩上 + 手掌按在他胸口 + 踮脚亲一下 → 转身就走，他僵在原地。

**两种都要求**：末镜 `intensity = 5`，台词 ≤ 12 字，必须有 1-2 个音效，时长 ≥ 8s。

## 五·五、野外做菜（野炊版）：石头灶 + 旺火

> ep05《清炒折耳根》实测。用户要求「在野外用石头搭灶，就在石头上炒，火要烧旺」。

**厨房那套不能直接搬**。野外做菜有三个差异：

| 维度 | 厨房 | 野外（石头灶） |
|---|---|---|
| 灶台 | 不锈钢灶台 + 抽油烟机 | **灰河石垒的圈**，铁锅架在石头上 |
| 火 | 燃气蓝火，均匀 | **木柴旺火**，橙红高窜，舔着锅沿 |
| 案板 | 不锈钢台面 | **河边的平石** |
| 光 | 顶部工作灯 | 自然光 + 火焰暖光 + 斑驳树影 |

**提示词要点**：
```
a rough circle of grey river stones laid as a primitive open-air stove,
a black iron wok set into the stone ring over a roaring orange wood fire,
tall flames licking up the wok's sides, the wide green river curving past behind,
misty blue-green mountains on the far bank, dappled sunlight through the branches
```

**火力要写足**：`roaring` `tall flames licking up` `surging around it` `burning bright and strong`。
火力不够就变成"室内小火慢煨"，观众立刻出戏。

**音效**：`flame` 用 **-8dB 起步**（压过 sizzle），才有野火的声势。
`woktoss` 可以给到 -9dB（比厨房响，因为空旷）。

**野外做菜段的镜头顺序**（跟厨房不一样）：
```
垒石灶（wide，要能看到石头）→ 点火（stove，火要窜起来）
→ 河边洗净切段（wok 特写，案板是石头）→ 热锅凉油（wok）
→ 大火快炒（wok，峰）→ 装盘（eat）
```

**关键**：灶台机位**必须能看到石头**，不然观众以为还在厨房。
场景锚写「灰河石灶圈」，机位描述也写「the rough circle of grey river stones」。

## 六、AI 编剧提示词要点

`STORY_SYSTEM` 里对应的规则（已内置）：

- **3 秒钩子**：第 1 镜就要出现「麻烦/挑战」，不许铺垫日常。
- **不许吵架**：反派挑衅后，主角的回应是**把菜端上**，不是回嘴。
- **每15 秒一个爽点**：刀工 → 扔刀 → 大颠勺 → 装盘 → 认输 → 夸，六个爽点均匀铺满。
- **炒菜段零台词**：明确告诉编剧「这几镜不写台词」，否则它会忍不住给厨师加解说。
- **反派必须有耳朵**：狼/狐狸这类尖耳角色，情绪全写在耳朵上（耷拉=认输、贴平=发怒、
  竖直=警觉），比写「他很生气」有效得多。
- **结尾只有两种收法**：征服顾客，或被老婆夸。不要「两人并肩看夕阳」这种淡收场。
