---
description: 查看 Agnes Clip 项目的进度（角色/道具/场景板/首帧/视频/配乐/成片各到哪一步）
argument-hint: "[项目目录，不给就自动找当前工作区最近的项目]"
---

定位本 skill 的 `ac.py`（`~/.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py` 或项目 `.workbuddy/skills/` 下的同名文件），用 Python 3.13.12 执行：

```
<ac.py路径> status "<项目目录>"
```

**没给项目目录时**：在当前工作区下找 `projects/*/project.json`（或任意含 `project.json` 且有 `title` 字段的目录），取最近修改的那个；一个都没有就告诉用户「当前工作区没有 Agnes Clip 项目，先做一个」。

输出后给用户讲清楚这几件事（用大白话，别把整个日志糊上去）：

1. **走到哪一步了** —— 角色、道具、场景板、首帧、视频、配乐、成片，各自的「已完成 / 总数」
2. **卡在哪** —— 第一个没到满的环节就是下一步该干的活
3. **提醒验收** —— 首帧到齐不等于能出视频，首帧要人眼过一遍（人数对不对、有没有多出来的人、左右站位对不对）

如果视频段数少于镜头数，直接告诉用户用 `--only` 单独补哪几镜：
```
<ac.py路径> video "<项目目录>" --only S07 --wait
```
