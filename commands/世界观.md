用 `agnes-clip` skill 的世界观工作台，把当前片子的所有设定摊开在一个网页里看和改。

定位 `ac.py`：`~/.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py`，用 Python 3.13.12 执行：

```
<ac.py路径> worldview "<项目目录>"
```

**没给项目目录时**：在当前工作区下找含 `script/shots.json` 的目录（或 `projects/*/`），取最近修改的那个；
一个都没有就告诉用户「当前工作区没有片子，先做一个」。

浏览器会自动打开（`http://127.0.0.1:8777/`）。如果没弹，手动开这个地址。

## 页面里有什么

左边两栏：
- **剧集** —— 同系列的所有集都在这，点一下就切过去（多集一目了然）
- **栏目** —— 世界观 / 剧本 / 分镜 / 角色 / 道具 / 场景

右边是内容：
- **世界观**：直接改 Markdown，保存写回 `世界观.md`（没有就新建）。多集共用的设定放系列根目录那份
- **剧本**：一句话梗概 + 叙事类型 + `story.md` 正文，都能改
- **分镜**：每镜的台词、角色、动作、微表情、场景、首帧提示词、视频提示词，点标题展开（只读）
- **角色**：定妆图、中英文描述、音色、服装是否锁定、是不是共享库里的 —— **描述/音色/服装锁定都能改**
- **道具 / 场景**：参考图、陈设、机位表、每场包含哪些镜头 —— **道具描述能改**，场景只读

顶栏有实时统计：多少镜、已出片几个、已出首帧几个、多少角色道具场景。

## 改完之后

- 页面右上角点「保存」，直接写回磁盘
- **分镜的提示词建议让 AI 改**（`vp.py` 风格的长提示词手改容易出错），页面里主要用来看
- 改完角色描述或服装锁定，记得让 AI 重新出一遍首帧

## 给用户的说明

用大白话讲清楚：这个页面是干什么的、能改什么、改完怎么落盘、多集怎么切。
如果用户问「改了会不会影响已经出的片子」，要说明：**分镜表改动不会自动重出片**，
需要自己决定重跑哪些镜头（`ac.py video --only Sxx --wait`）。
