---
description: 给指定项目选一条出图通道（Agnes / GPT Image / 自定义 OpenAI 兼容），只影响这个项目
argument-hint: "<项目目录> [通道名]，如 E:/projects/xxx gpt-image"
---

定位本 skill 的 `ac.py`（`~/.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py` 或项目 `.workbuddy/skills/` 下的同名文件），用 Python 3.13.12 执行：

```
<ac.py路径> pick-image "<项目目录>" --channel <通道名>
```

通道名只能是这三种之一：
- `agnes` — 走 Agnes 云端生图（默认，稳）
- `gpt-image` — 走 OpenAI 兼容 /images/generations 的中转
- `openai` — 同上，语义别名

**不写通道名**就表示「清除项目级设置，回到跟随全局」。

执行完把命令输出的「当前通道 / 端点 / 模型」念给用户听，让他确认这个模型他的 Key 有权限用。

补充说明（要讲人话，别堆术语）：
- 项目级设置写在那个项目的 `project.json` 里，**只影响这一个项目**，不会动全局配置。
- 全局默认通道在配置页「生图」TAB 里改，影响所有没单独指定的项目。
- 换通道后，之前生成的首帧不会自动变。要重出的话跑：
  `<ac.py路径> frame "<项目目录>" --force`
- 通道按「项目开始时选」的习惯用：每个新片子开工前先跑一次 `pick-image`。
