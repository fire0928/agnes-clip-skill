# 剧本逻辑自检清单（logic_check）

> 用户明确要求：**从剧本阶段就要判断逻辑全不全；出了视频也得检查。**
> 逻辑不闭合的片子，观众会觉得莫名其妙。

## 一、剧本阶段（写分镜时就要过）

### 1.1 因果链闭合（最重要）

每一镜必须能回答：**观众凭什么知道下一镜会发生什么？**

逐镜检查：
- 上一镜提供了**动机/触发/线索**吗？
- 本镜的动作是**回应**上一镜吗？
- 本镜的台词在**回答**上一镜的问题吗？

反例（ep03 实测踩过）：
```
S08 猫嫂发火骂猫哥      ← 冲突到顶
S09 猫嫂看模糊的电视画面  ← ❌ 观众不知道电视里在播什么
S10 猫嫂「猫哥他，去帮人做饭了？」← ❌ 这句台词接不上，观众懵
```
修法：补一镜「电视里正在播报『青年帮老人』」，让信息先到，观众才知道猫嫂为什么突然软下来。

### 1.2 转折依据检查（转折镜专用）

凡是 `purpose = 转折` 或 `高潮` 的镜，**前两镜内必须已经出现让观众能想到这个转折的线索**。

| 转折 | 必须先铺的线索 |
|---|---|
| 真相被揭穿 | 先给「不对劲的细节」 |
| 和解 | 先给「双方各自的心软迹象」（互相看一眼、犹豫、道歉的话先说一半） |
| 身份暴露 | 先给「掩体/说辞/行为异常」 |
| 反败为胜 | 先给「被压制/资源不足」+「主角的小聪明」 |

### 1.3 新信息镜检查

凡是**首次引入一个新元素**（电视播报、第三方角色、关键道具）的镜，
后面**必须至少有一镜明确反应它**，否则这个元素是白给的。

- 反例：加了「电视播报」，但后面只有猫嫂看屏幕的模糊特写 → 信息没落地
- 正例：加了「电视播报」，播报内容清晰（播报员 + 内容 + 字幕），猫嫂接着说「他帮老人去了」

### 1.4 问答闭环（问了就必须有人答）

**A 角色问了什么，下一镜必须有人接。** 最常见的破绽：A 问了一句，下一镜 A 直接退场、
只剩 B 在讲别的事——这句问就白问了，观众会一直等着听答案。

- 反例：S04 羊大爷问「小伙子，你跟谁住一块啊？」，猫哥一句没答就切到下一镜
  （下一镜是灶间，只有猫哥一个人），对话悬空，整段像剪断了
- 正例：加一镜猫哥扭头作答「就我一个，媳妇儿在家守店呢。」
  —— 补上回答的同时还能埋伏笔（他随口说媳妇在守店，后面她守着空锅发火就有因果了）

三条判定规则（`ac.py check` 自动跑）：

1. 问句 = 以「？/?」结尾，或句尾带「吗/呢」，或结尾三字内有「谁/哪儿/哪里/为何/多少」
   （句中带「谁」但其实是陈述的不算，避免误报）
2. 提问者不在下一镜的 `cast` 里 → 没人能接；若下一镜说话人不是电视主播/画外音/电话那头
   （`anchor`/`vo`/`news`/`announcer`/`reporter`/`tv`/`radio`/`phone`）→ **报「问句悬空没人接」**
3. 提问者在下一镜画面里，但那镜的台词不是应答（不共享实词、也不是「嗯/是/对/我/就」这类应答开头）→ **报「问句被晾在一边」**

例外：自问自答（对空说话，「我怎么知道？」然后自己答）是合法的，不报。

### 1.5 删一镜测试

删掉任意一镜，故事是否仍然完整？若某镜删掉毫无影响 → 它是废镜，要么重写要么合并。

特别检查**过场镜**（「一行人赶到河边」「大家开始收拾」这类）——
它们最容易被写成风景介绍，删了故事反而更顺。

群戏里每一个出场角色都要有**存在理由**：谁是来帮忙的？谁只是凑热闹的？谁有名词/有动作？
纯凑人数的角色要么给他一句台词，要么让他别出现。

## 一·五、结构级硬伤（ep05 实测，用户反馈「情节不顺畅」）

> 前面 1.1–1.7 检查的是**字段完整性**（`because` 有没有填）。
> 下面这几条查的是**结构本身有没有毛病**——
> 逐镜看都通，连起来看「怎么突然就…」「问的和答的不是一回事」。
> 靠人眼看 22 镜很难不漏，必须机器查（`ac.py check` 已内置，v1.19.0）。

### 1.5·一 问句和答句必须是同一个问题

问的是**价格**，答的是**好不好吃**——被问的人全程没答那句问，观众会一直等着听答案。

- 反例（ep05 原版）：
  ```
  S16 猫嫂「大爷，您这折耳根，一斤卖几个钱？」   ← 问的是价
  S17 猫哥「您尝尝，值不值这个价。」              ← 答的是值不值（好不好吃）
  ```
- 正例（同一句里先答后转）：
  ```
  S17 猫哥「三毛一斤，您尝尝，值不值这个价。」
        ↑「三毛一斤」正面答了价格，后面才转话题
  ```

**检查方法**：把每一对「问句 → 下一镜台词」并排读一遍，问句的话题必须被覆盖。
话题分类：价 / 值 / 好吃 / 哪 / 谁 / 怎么 / 为什么 / 是不是。

### 1.5·二 冲突方不能天降

反派/找茬的人**第一次出现**时，前面必须已经交代过他的存在或来由。
否则观众第一个问题是「他刚才在哪、怎么现在才发现」。

- 反例（ep05 原版）：猫哥他们挖了 14 秒的折耳根、垒灶炒完菜，
  老汉才慢悠悠从坡上走上来——**冲突是硬塞的**。
- 正例：坡边有一块**旧界碑**，猫哥他们挖的时候就在那儿、路过没当回事（观众看到了、记住了），
  老汉**从界碑那边走出来**——冲突一下就有了根。

**三种合法铺垫**（越具体越好）：

| 方式 | 例子 |
|---|---|
| 画面线索 | 旧界碑 / 围栏 / 标牌 / 石柱 —— 主角经过时没当回事 |
| 台词线索 | 路人提过「这块地有人管」「那户脾气不好」 |
| 主角说漏 | 「这是谁家的地来着？」——没人接，埋下祸根 |

🔴 **画面线索必须真的画出来**（写进 `frame.prompt`）。
光在 `because` 字段里写不算——观众看不见。

### 1.5·三 人跑了就别再莫名回来

某一镜写了「一窝蜂跑掉/落荒而逃」，下一镜又「聚回来吃饭」——
中间没交代折返，观众会懵「跑了怎么又回来了」。

- 反例（ep05 原版）：S20 一行人端起锅就跑 → S21 野炊宴又坐回去吃饭。
- 正例（**不删镜**的修法）：把离场改成**喜剧小插曲**，
  下一镜明确写「猫哥追上去把他请了回来」——
  逃跑和回来变成同一件事的两半，逻辑闭合。

**三种合法写法**：① 干脆删掉离场镜；② 改成喜剧插曲 + 下一镜交代「请回来」；
③ 离场本身是剧情的一部分（去搬东西/救人），下一镜交代去向。

### 1.5·四 新角色入场要有存在理由

每个新角色第一次出现，要能回答「他为什么在这儿」。
尤其是**冲突方家属**这种「从哪冒出来的」角色——
ep05 里祥婶是老汉的老婆，中途走上坡，观众会问「她刚才在哪」。

---

### 1.6 情绪曲线

- 全片至少一个最低点（谷）和一个最高点（峰）
- 禁止连续三镜同一 `intensity`
- **最后一镜必须是峰或接近峰**，且带一个具体肢体动作（见 `ending_modes.md`）

### 1.7 信息量守恒

观众在第 N 镜**已知的信息**，必须足以理解第 N+1 镜。
反过来，台词里出现的每个信息，观众都该在之前见过——除非是刻意的「揭晓」，那必须有铺垫。

## 二、出片后（视频已生成，逐镜复查）

出片不等于过关。成片必须再看一遍：

| 检查项 | 怎么查 | 不合格的表现 |
|---|---|---|
| 逻辑链是否在成片里成立 | 抽帧 + 看字幕，按顺序读一遍 | 观众能看出「少了/多了」一环 |
| **问答有没有闭环** | 念字幕时重点听「上一句问、下一句有没有人答」 | 有人问了句什么，下一句是另一个人讲别的事 |
| 人物朝向 | 看对话镜两人是否相对而立、视线交汇 | 两人都看镜头（观众像在看直播） |
| 人物数量 | 每镜人数与剧本一致 | 多出人、少人 |
| 台词时机 | 字幕出现时嘴在动 | 字幕早了/晚了，画面没对上 |
| 台词内容 | 字幕文本 = 剧本台词 | 字幕写错、串行 |
| 道具 | 台词提到的实物在画面里 | 说「两碗面」只有一碗 |
| 结尾高潮 | 最后一镜有没有演完动作 | 动作没做完就切黑 |
| 时长 | 成片时长 vs 计划 | 明显短一大截（多半是 xfade 静默截断） |

### 抽帧验收的落地做法

```bash
# 每 3-5 秒抽一帧，人眼看一遍
ffmpeg -i out/final.mp4 -vf fps=1/3 q/v=2 qa/frames/t%02d.jpg
```

看的时候按顺序读字幕，把字幕连起来念一遍 —— **念不顺就是逻辑断了**。

## 三、工具化

`ac.py check <dir>` 会自动跑以下检查并打印问题清单：

- 每镜 `because` / `audience` 是否填（因果链字段）
- `intensity` 曲线是否有峰有谷、有无连续三镜相同
- 末镜有没有 `ending_mode`、`intensity` 是否够高、有没有动作
- 转折镜前两镜有没有铺垫线索
- 台词字数、景别跨度、同框人数

**手工检查仍然必须做** —— 工具查不出「逻辑断在半路」。
