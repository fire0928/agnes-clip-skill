# 叙事设计（为什么 AI 写的剧本没逻辑，以及怎么修）

## 症状诊断

AI 写分镜的默认行为是**意象流**：海边、古塔、雪、雨、撑伞、回头——每一段单看都美，但段与段之间只有「并列」关系，没有「因果」。

具体表现：

| 症状 | 观众的感受 |
|---|---|
| 每镜之间接不上 | "她怎么又到这儿了？" |
| 去掉任意一镜也不影响 | "这段是凑数的吧" |
| 第一镜和最后一镜的她没区别 | "所以呢？" |
| 全是"站着看"，没有"做一件事" | "像换装展示，不像故事" |
| 没有情绪最低点或最高点 | "一直平，看得累" |

**根因不在模型，在流程**：从"概念"直接跳到"分镜"，中间缺骨架。AI 只好用意象填空。

## 三个必备骨架

### 1. 一句话故事（logline）

格式：**谁 + 想要什么 + 遇到什么阻碍 + 最后变成什么**

没有 logline 就开始写分镜，必然散。

反例（《千年一梦》初版）："一个女孩穿越十个朝代，穿不同的衣服。"
——这里只有"做什么"，没有"想要什么"，也没有"变化"。所以十段是并列的，观众看完记不住任何一段。

正例："她想弄明白千年前的人怎么活，于是借十件衣裳走进十个时代；她只能看不能留，最后发现衣裳记得时代，而人只记得自己。"

——有了欲望（弄明白）、阻碍（只能看不能留）、变化（从旁观到释然）。

### 2. 情绪曲线

每一镜标一个情绪值（-5 到 +5），必须满足：

- 至少一个**最低点**（转折的起点）
- 至少一个**最高点**（情绪释放）
- 不能连续三镜同值（否则"一直平"）

《千年一梦》重排示例：

| 镜 | 情绪值 | 情绪 |
|---|---|---|
| S00 航拍 | +1 | 期待 |
| S01 海边 | +2 | 好奇 |
| S02 唐·大雁塔 | +4 | 惊叹 |
| S03 敦煌夜 | +5 | 敬畏（最高） |
| S04 汴京 | +3 | 欢喜 |
| S05 西湖雨 | +1 | 安静 |
| S06 紫禁城 | -1 | 压抑 |
| S07 拙政园 | -3 | 孤独（最低点） |
| S08 故宫雪 | -2 | 克制的温柔 |
| S09 乌镇 | +2 | 释然 |
| S10 海边 | +3 | 平静的满足 |

有了这条曲线，S07 的孤独就不是"随便放一段园林"，而是**必须存在的情绪谷底**。

### 3. 母题回环

一个具体元素贯穿全片，开头出现、结尾回应：

- 物件：一件衬衫 / 一片瓦 / 一朵花
- 动作：赤脚踩水 / 回头看 / 摸一下墙
- 一句话：开头说一半，结尾说完

《千年一梦》做法：S01 她赤脚站在海边，手里空着；S10 同一片海边，她手里多了一片瓦（从某个朝代带回来的）。

——观众不一定注意得到，但会"感觉到"完整性。

## 每镜必须回答的四个问题

写任何一镜之前，先填这四个空：

1. **这一镜的作用**：推进 / 停顿 / 转折（三选一，不允许"没有作用"）
2. **因为上一镜**：______，所以这一镜 ______
3. **她在这里做什么**：必须是一个动作，不能是"站着看"
4. **观众看完应该想**：______

第 2 条是杀废镜的刀：**填不出来就说明这镜该删**。

## 剧本工单（用户填，AI 只负责执行）

不要让 AI 决定故事，只让它执行。开工前先填这六行：

```text
我想让观众感觉到：____（一种情绪，如"释然""不甘""被理解"）
主角想要：____
她的阻碍：____
最后她明白了：____
必须出现的画面：____（最多 3 个，多了就散）
绝对不能出现的：____
```

填完再让 AI 拆分镜。**AI 的自由度只在"怎么拍"，不在"拍什么"。**

## 与 H3 的配合

有骨架之后，每镜的 video_prompt 就有了依据：

| 骨架要素 | 落到提示词哪里 |
|---|---|
| 她的动作 | 时间轴第一句（必须是动作） |
| 情绪值 | 微表情的强度（+5 用明显表情，-3 用克制） |
| 因果 | 上一镜结尾的构图 / 动作，作为这一镜起手 |
| 母题 | 每镜都带那个物件（或暗示它） |

## 检查清单（写完必过）

- [ ] 每镜都能用"因为上一镜…所以这一镜…"接上吗？
- [ ] 随机删掉一镜，故事是否残缺？（不残缺 = 废镜）
- [ ] 第一镜和最后一镜，主角有什么不同？
- [ ] 有没有明确的最低点和最高点？
- [ ] 母题出现了吗？结尾回应了吗？
- [ ] 每镜都有动作，还是都在"站着看"？

六条里有任何一条不过，就不要往下跑视频——**十段视频跑八十分钟，剧本错一句全废**。
