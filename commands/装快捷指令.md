把本 skill 自带的 `commands/` 目录复制到 WorkBuddy 的命令目录，让用户在对话框输入 `/` 就能看到这些快捷指令。

**步骤**：

1. 定位本 skill 目录（`~/.workbuddy/skills/agnes-clip-平哥分享版/`，兼容项目级 `.workbuddy/skills/` 下的副本）。
2. 源目录：`<skill目录>/commands/`
3. 目标目录（**两个都装**）：
   - 用户级：`~/.workbuddy/commands/`（全局可用）
   - 项目级：`<当前工作区>/.workbuddy/commands/`（只在这个项目可用）
4. 用 Python 3.13.12 复制（Windows 上别写 .ps1/.bat 脚本，中文路径会乱码，直接调命令行）：
   ```
   <python3.13.12> -c "import shutil,os; s=r'<skill目录>/commands'; [ (os.makedirs(d,exist_ok=True), shutil.copy2(os.path.join(s,f), os.path.join(d,f))) for d in [r'~/.workbuddy/commands'.replace('~',os.path.expanduser('~')), r'<工作区>/.workbuddy/commands'] for f in os.listdir(s) if f.endswith('.md') ]"
   ```
5. 复制完列一遍装上了哪几个命令，告诉用户**需要重启 WorkBuddy 才会出现在 `/` 列表里**。

装完会有的命令：

| 命令 | 干什么 |
|---|---|
| `/出角色卡` | 生成角色设定卡（正脸 + 多格设定稿 + 角度图），给人过目造型 |
| `/配置` | 打开配置界面（出图/推理/视频/配音/配乐，7 个 TAB） |
| `/出图通道` | 给指定项目选一条出图通道 |
| `/片子状态` | 看项目进度到哪一步 |
| `/做一条片子` | 从一句话创意开始做一条短剧 |
| `/重切角度图` | 从已有设定卡重切正/侧/背角度图 |
| `/配乐台` | 试听配乐、逐镜调音量 |

**同名命令以本 skill 自带为准**：以后升级了 skill，重跑一次 `/装快捷指令` 就能把旧的覆盖掉
（同名覆盖、不同名新增）。想先看看有没有需要更新的，加 `--check`：

```bash
<python3.13.12> <ac.py路径> --check
```
