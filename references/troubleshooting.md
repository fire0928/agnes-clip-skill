# 崩坏对照表

## A. 人脸类（最高优先级）

| 现象 | 真实原因 | 修法 |
|---|---|---|
| 某一帧五官突然挤压、脸变形，前后帧正常 | 提示词里有 `cut to` 硬切 | 改 `ONE continuous steadycam take, no cuts` |
| 整段的脸都崩（歪嘴、大小眼、五官糊） | 用了 `close-up` 怼脸，脸部占比过大 | 改 `waist-up medium shot` |
| 第 N 秒人物突然变成另一个人 | (a) 提示词描述了长相 与首帧冲突；(b) 景别跨度太大 | 删掉长相描述；景别压缩到 2 倍内 |
| 第一个镜头像本人，后面越来越不像 | 用尾帧接力做首帧，误差累积 | 改原图锚定，每段都从 face_ref 出发 |
| 换装后脸被"美颜"（瘦脸、眼大、磨皮） | 千问 char 模式的固有倾向 | cfg 提到 5.0 + 写"反美颜"清单 + 逐张验收 |
| **换成古装后整个人变了** | 模型对"古代服装 + 现代脸"有冲突先验，会自动把脸也"古装剧化" | ①提示词改成**参照式**："只更换服装/发型/背景，脸部不做任何改动，与参考图保持一致，不美化不修正"；②**绝不要描述原图长相**（写"圆润脸颊"会画成娃娃脸，写"偏短下巴"会缩短下巴）；③cfg 用 4.5，别用 6.0（会过度执行修正）；④视频端加 `No beautification, no skin smoothing, no enlarged eyes` |
| 视频近景仍轻微美颜 | 生成模型在古装语境下的固有倾向，提示词只能压制不能根除 | 接受轻微差异；或在分镜设计上避免"古装 + 腰以上近景"，改用中景/侧脸/背影表达情绪 |
| 三个人以上同框，脸开始串 | 同框角色过多 | 拆镜头，同框 ≤2 人 |
| 侧脸/转身时脸崩 | 侧脸信息少，模型自由发挥 | 转身镜头只做肩部以上小幅转，不要 180° |
| **真人邻居长出兽脸**（人变狐狸/狗） | ①skill 无条件追加「所有角色的手都是动物爪子」，和真人声明打架；②世界观锚的通用动物描述被套到真人身上；③`project.json` 漏写 `character_type` 导致混入 EAST_ASIAN 句 | 三处一起修，详见 `human_and_props.md` 一点五（ep05 S18 事故）。skill v1.19.0 已内置 |
| **特写镜变成站立人物中景** | 提示词写了「tight close-up…only paws visible」，但 skill 自动追加的「人数白名单 + 两人相对而立」跟它打架，模型照**后写的那句**画 | 加 `shot.no_faces = true`（skill v1.19.0）：不喂人脸图、不追加人数和站位句、改用极近景白名单 |
| **特写镜里运镜把脸带进画** | 视频模型独立生成链，会在运动中把主体「带进画」 | 视频提示词补一句「全程极近景，脸和身体永不入画，人在手腕手肘处裁切」 |
| 猫/动物长出人类五官 | `project.json` 漏写 `"character_type": "anthropomorphic_animal"`，混入了「All characters are East Asian Chinese…」 | 拟人动物项目必须显式写这个字段（漏了不报错，只是画面悄悄变味） |


## B. 画面与背景类

| 现象 | 原因 | 修法 |
|---|---|---|
| 背景像一张平面贴图，没有纵深 | 提示词写了颜色光带（"violet neon glow"） | 换实体清单：桁架、雾机、湿地面反射、观众手机屏光、真实屏幕内容 |
| 背景很"旅游照"、很假 | 只写了景点名，没写材质与生活痕迹 | 加"磨损的石板、锈迹、水痕、灰尘在光束里" |
| 人物像贴上去的，光影不融合 | 没写光的来源与方向 | 明确写主光位置（"warm lamp from her left, cold blue from the window"） |
| 画面发灰发闷 | 步数不够或 cfg 过高 | 4 步 → 5 步；cfg 降到 4–4.5 |
| 颜色过饱和像塑料 | 堆了太多风格词 | 风格词 ≤3 个，加 `muted`, `true-to-life` |
| 构图切头切脚 | 首帧图裁切比例错 | `ImageScale crop=center`，源图先按 9:16 居中裁 |
| **整个场景换了一家店** | 该镜的 `angle` 没有对应场景板 → 没喂场景参照，模型自由发挥 | 建集时先定机位清单再把板补齐；或把 `angle` 改指到已有板的机位（ep07 S13 事故） |
| **场景画成日式居酒屋**（障子门、纸灯笼、和风挂轴） | ①`no_plate=True` 纯靠文字；②写了否定句 `NOT a Japanese restaurant` | 喂场景板；场景描述**只写"有什么"**，否定句会反激活（ep07 事故） |
| 场景板里的陈设和别的镜对不上 | 场景板是从别的集复制来的，内容根本不是这家店 | **场景板必须先打开看图**，文件名对不代表内容对；拿不到干净板就从已画对的画面裁纯背景 |
| 场景板里莫名画出一只穿褂子的猫 | `scene.angles` 的机位描述里写了角色名 | 机位描述**只写环境**，不许出现角色（ep12 事故，9 张板全废） |
| 场景变成网红大店、地面大片光斑 | anchor 没写规模；`light` 只写 sunlight | anchor 写 `a SMALL ... only a handful of tables`；`light` 写室内主光 + 少量低角度阳光 |

## B2. 镜头语言类（ep11 实测，观众直接骂出来的）

| 现象 | 原因 | 修法 |
|---|---|---|
| **「对话的时候要有特写镜头来展现表情细节」，但全片没一个特写** | 31 镜全是 medium / medium two-shot，一集只有 1 种景别 | `shot_size` 按配比排：medium close-up 占 35%、insert 占 15%；`ac.py check` 现在会查特写占比（<30% 报错） |
| **「镜头语言过于死板」** | 30/31 镜没有任何运动描述，模型自己回落成"平视中景居中静止" | 每镜的 `camera` 句里要么一个运动，要么明写 `static camera, locked-off tripod` |
| **「角度一会儿又变了一会儿又变了」** | 机位句只写了景别（`medium two-shot across the counter`），没写焦段/机位高度/物理锚点，模型每次自己挑角度 | 机位句必须带物理锚点：`camera resting on the counter, 85mm, eye level`；同一机位的句子逐字相同 |
| **同一场戏看着像换了好几个机位** | 同上——"机位只有一种"≠"角度稳定" | 同上 |
| 剪在一起画面抖了一下（跳切） | 相邻镜同景别 | 相邻镜换一档景别；`ac.py check` 会查连续 3 镜同景别 |
| 同一角色一会儿画左一会儿画右 | 越轴 | 同一机位的左右写死；`ac.py check` 会查左右翻转 |
| 两个人在竖屏里像合影、脸小得看不清 | side-by-side two-shot | 交替单人 / 纵深堆叠 / 过肩，详见 `shot_coverage.md` 第三节 |
| 一镜里镜头动，人物口型对不上 | 对话镜用了运镜 | 对话镜 static 或极缓推 |
| 4–6 秒短镜出来像抽帧 | 短镜塞了环绕/升降 | 短镜只做推/极缓推/定点 |

## C. 动作类

| 现象 | 原因 | 修法 |
|---|---|---|
| 动作抽搐、人物瞬移 | 一个镜头塞了多个动作 | 拆镜头，一镜一动作 |
| 走位像滑行 | 没给步频/时长 | 写 `walks three steps in 4 seconds` |
| **前 1–2 秒重影/拉伸/糊帧，后面正常** | 首帧机位与运镜起点冲突（如自拍近景 + 航拍俯冲） | 换首帧（改用远景图）或换运镜（改推镜/拉镜）。详见 `camera_language.md` 航拍第 1 条 |
| 生成时长比设定短 0.5–0.7 秒 | 帧数换算向下取整 | 用 `17n+5` 向上取整：10s→243、8s→192、5s→124 |
| 手变形、手指糊成一团 | 手部特写 | 避开手部特写；手自然下垂或扶栏杆 |
| 衣服在中途变形/穿模 | 一个镜头内换了装，或动作幅度过大 | 换装必须换镜头 |
| 转身时身体拧麻花 | 转身幅度过大 | 只写到"转向肩膀、侧身展示" |

## D. 系统与流程类

| 现象 | 原因 | 修法 |
|---|---|---|
| 提交报 `Prompt outputs failed validation` | 节点参数名/类型不对 | 对照 `object_info` 查真实签名；DynamicCombo 要点号拍平（`mode.width`） |
| 生成 `CUDA out of memory` | 帧数×分辨率超显存 | 降帧数（17n+5）或降分辨率（32 的倍数）；243 帧 704×1280 峰值约 19.8G |
| 千问报 OOM 但只差几十 MB | 与 27B 共用卡，显存碎片 | 等 3 分钟让模型卸载（`QI_IDLE_SEC=180`）；或 `sudo systemctl stop qf-vllm` |
| 上传首帧后 LoadImage 找不到文件 | 文件名带中文/空格 | 用纯英文短名；`vp.py` 会按原文件名上传 |
| 下载的视频 0 字节 | 用 `stat` 和 `cat` 混流污染了文件 | 下载时只走 `cat` 单流；优先用 `/view` 接口 |
| 拼接后音画不同步 | 各段采样率/时基不一致 | concat 前统一 `setsar=1`，音频 `aresample=44100` |
| 接力帧覆盖了原始首帧，audit 对不上 | 旧代码把上一镜尾帧直接写进 `frames/<sid>.jpg`（v1.23.0 已修） | 接力帧改落 `frames/_chain/<sid>_in.jpg`；重跑 `frame --only` 可随时恢复原首帧 |
| 有人物的镜尾帧连传后脸漂了 | `link` 连传超过 2 段，脸一镜一镜累积漂移（ep04 事故） | 第 3 段起改 `tail_frame: "next"`（两端锚首帧）；无脸特写连传不限 |
| 分镜之间跳、像 PPT | 各镜首帧独立生成，构图/色调/机位不连续 | `ac.py chain` 一键配对（特写链用 link、同场景人物镜用 tail_frame），出片后 `seam` 验收 |
| 最终音量忽大忽小 | 直接 amix 未做归一 | `amix normalize=0` + `volume` + `alimiter`；不要用单遍 loudnorm（会把采样率顶到 96k） |
| **某些角色的台词整集没声音** | `characters[].voice` 写了一个 **edge-tts 不存在的声线名**。它不报错，只返回空音频，日志里只有一行 warn，配音命令仍然 exit=0 | v2.0.0 起 `voice` 前置校验声线名，写错直接报错并列出可用清单。可用中文声线只有 8 个：`Xiaoxiao`（温柔女）`Xiaoyi`（活泼女）`Yunjian`（沉稳男）`Yunxi`（阳光男）`Yunxia`（**男童**）`Yunyang`（播音男）`liaoning-Xiaobei`（东北女）`shaanxi-Xiaoni`（陕西女）——**没有** `XiaomoNeural`、`YunyeNeural`（ep06 踩过，小猪和羊大爷 8 句全哑） |
| 配音目录里出现 `<sid>.mp3.part0.mp3` | 第一次合成失败、回退重试的中间产物 | 正常现象可删；若 `S19.mp3` 本身存在且 >1KB 说明最终成功了 |
| 重跑生成器后 `check` 又冒出一堆老问题 | 修正写在后置补丁脚本里，一重新生成镜头表就全丢 | **所有修正必须写进 `tools/make_ep0N.py` 的 `shot()` 调用本身**，别靠 `fix_*.py` |
| **Windows 上跑着跑着崩了：`UnicodeEncodeError: 'gbk' codec can't encode character '\\U0001f534'`** | cmd.exe 默认 GBK，编不了代码里用的 `🔴 ✅ ❌ ⚠ ▸` 符号；崩在 print 上，跟真正的错误毫无关系 | v2.0.0 起三个入口脚本自动切 UTF-8（`errors="replace"` 兜底）；仍遇到就 `chcp 65001` |
| **合成时 ffmpeg 一直挂着不返回** | ffmpeg 读不到输入路径 / 滤镜死循环 / 磁盘满 | v2.0.0 起 `ff_run()` 有 30 分钟超时，超时会报明确原因；先查输入文件是否还在、磁盘剩余空间 |
| **凭据文件/镜头表变成半截，提示「配置文件损坏」** | 写到一半崩溃（断电/Ctrl+C/磁盘满）留下残缺 JSON | v2.0.0 起 `save_json()` 改原子写（临时文件 + `os.replace`）；已经损坏的只能手改回来 |
| **`fetch` 报"有镜头失败"，但不知道是哪几个** | 旧版无条件删了 `_pending.json`，失败状态被抹掉 | v2.0.0 起失败时保留 `_pending.json` 并打印清单；可再跑 `fetch` 继续 |
| **本地网页服务被别的网站改内容** | 只监听 127.0.0.1 不防 CSRF：浏览器里打开的任意网页都能 POST 到本机服务 | v2.0.0 起所有写接口校验 Origin + Host，跨站返回 403（见 `scripts/web_guard.py`） |

## E. 排查顺序（从便宜到贵）

1. 看提示词里有没有 `cut` / `close-up` / 颜色光带 —— 改文字，不花钱
2. 看首帧图对不对 —— 换一张首帧，几十秒
3. 换 seed 重跑这一段 —— 几分钟
4. 降分辨率/帧数重跑 —— 几分钟
5. 全部重跑 —— 最后手段
