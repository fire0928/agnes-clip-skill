# 机位系统（先定机位，再排镜头）

## 为什么分镜会"一会儿左一会儿右"

AI 写分镜的默认方式是**每镜独立描述运镜**：这一镜推、下一镜摇、再下一镜换个角度。单看每一镜都合理，连起来观众就晕——因为**没有一条统一的轴线**。

观众的感受是："她怎么突然跑到右边去了？"——这就是**越轴**。

根因：写分镜时脑子里没有"这个场景有几个机位"，只有一个接一个的"好看的镜头"。

**解法：机位先定，镜头只能从机位表里选。**

## 三机位法（双人场景的标准解）

一个场景只要三个机位，够用，而且绝对不会跳。

| 代号 | 名称 | 作用 | 摆在哪 | 焦段 |
|---|---|---|---|---|
| **A** | 主镜头 Master | 交代空间、两人站位、关系 | 与两人连线**垂直**的一侧，能同时看到两人全身或大半身 | 35mm |
| **B** | 过肩 · 看甲 | 乙的视角看甲，甲在画左，乙的肩膀在画右前 | 乙的身后侧，越过乙的肩 | 50-85mm |
| **C** | 过肩 · 看乙 | 甲的视角看乙，乙在画右，甲的肩膀在画左前 | 甲的身后侧，越过甲的肩 | 50-85mm |

### 轴线怎么定（关键）

**两人连线就是轴线（180 度线）。A、B、C 三个机位必须都在线的同一侧。**

定好之后：

- 甲永远在**画左**
- 乙永远在**画右**
- B 机位（看甲）：甲在画左三分之一，乙的肩背在画右边缘
- C 机位（看乙）：乙在画右三分之一，甲的肩背在画左边缘

**全场景不许换边。** 换边 = 越轴 = 观众觉得人瞬移了。

### 越轴的三种典型错误

| 错误 | 表现 |
|---|---|
| 同场景两镜左右关系反了 | 一镜甲在左，另一镜甲在右 |
| 正反打拍成了同方向 | 两条过肩镜头都从同一侧拍，等于没切 |
| 全景与特写左右不一致 | master 里甲在左，特写里甲跑到右边 |

### 需要"过轴"时怎么办

只有两种情况可以过轴，且必须**用一个中性镜头过渡**：

1. 一个正面的双人镜头（机位压在轴线上）
2. 一个人物移动的镜头（镜头跟着人走过去，把轴线带过去）

不许硬切过轴。

## 建立镜头（第一镜必须交代什么）

用户的原话："先来一个推镜头，看到一个餐饮店里面，顾客坐着吃饭，老板娘从后厨端着一碗面走出来。"

这一镜要完成四件事：

1. **空间**：这是个什么地方（面馆、几张桌、后厨门在哪）
2. **人物**：谁在里面（顾客坐在哪一桌、面朝哪）
3. **关系**：两人的位置关系（一个坐着一个出来）
4. **轴线**：这一镜的落幅就定了甲在左还是右——后面所有镜头都跟着这个走

**写法**：一个连续运动镜头（推 / 移 / 摇）进入场景，落幅在双人构图上。不要一上来就切特写。

## 场景类型 → 机位模板

| 场景 | 机位数 | 配置 |
|---|---|---|
| **双人对话** | 3 | A 主镜头 + B 过肩看甲 + C 过肩看乙 |
| **单人独处** | 3 | A 全身环境 + B 中景（腰以上）+ C 细节（手 / 物件） |
| **单人移动** | 2 | A 后侧跟拍 + B 侧面平移 |
| **多人（3-6 人）** | 4-5 | A 主镜头 + 每个关键人物一条单人镜头，别超过 5 条 |
| **纯环境/空镜** | 1-2 | A 大景 + B 局部细节 |

**铁律：一个场景的机位数不超过 5 个。** 超过说明你在用"镜头数量"掩盖"没有调度"。

## 分镜表怎么记

场景和机位必须在 `shots.json` 里显式写出来，不能只写在脑子里：

```json
{
  "scenes": {
    "SC1": {
      "location": "深夜小面馆",
      "axis": "两人连线为轴；顾客在画左，老板娘在画右；机位全部在轴线南侧",
      "setups": {
        "A": { "type": "master", "desc": "从店门口推进，落幅双人全景，能看到后厨门", "lens": "35mm" },
        "B": { "type": "ots", "target": "顾客", "desc": "过老板娘右肩，顾客在画左三分之一", "lens": "50mm" },
        "C": { "type": "ots", "target": "老板娘", "desc": "过顾客左肩，老板娘在画右三分之一", "lens": "50mm" }
      }
    }
  },
  "shots": [
    { "id": "S01", "scene": "SC1", "setup": "A", "duration": 8, "note": "推镜进店，交代空间与站位" },
    { "id": "S02", "scene": "SC1", "setup": "B", "duration": 6, "note": "顾客视角：看老板娘端面过来" },
    { "id": "S03", "scene": "SC1", "setup": "C", "note": "老板娘视角：看顾客" },
    { "id": "S04", "scene": "SC1", "setup": "A", "note": "回到主镜头收尾" }
  ]
}
```

**每镜必须标 `scene` 和 `setup`。** 标不出来，说明这镜是凭感觉加的。

## 提示词里怎么写机位

机位要写成**摄影术语**，不能写"从左边拍"。

| 机位 | 英文写法 |
|---|---|
| A 主镜头 | `A WIDE MASTER SHOT from the doorway, both characters fully visible, the customer seated at the left table and the shop owner entering from the back kitchen on the right` |
| B 过肩看甲 | `OVER-THE-SHOULDER shot from behind the shop owner's right shoulder, the customer framed on the left third of the frame, the owner's shoulder soft in the right foreground` |
| C 过肩看乙 | `OVER-THE-SHOULDER shot from behind the customer's left shoulder, the shop owner framed on the right third, the customer's shoulder soft in the left foreground` |
| 单人独处 · 细节 | `CLOSE-UP on her hands, the bowl slightly out of focus behind` |

**每镜的提示词必须包含：景别 + 机位关系 + 人物在画面的哪一侧。** 缺了"哪一侧"，模型就会自由发挥，一自由发挥就跳轴。

## 和运镜的关系

机位定的是"站在哪拍"，运镜定的是"这一镜里镜头怎么动"。

- 机位 A（主镜头）：允许推、移、摇（建立镜头常用）
- 机位 B / C（过肩）：**以固定或极缓推为主**，不要大幅运动，否则两个过肩镜头的空间感不一致
- 一个场景里，运动镜头只能出现在 A 上；B 和 C 保持稳定

这条能解决"镜头跳"的另一半问题：**运动幅度不一致**也会让人觉得跳。

## 自查清单（写完分镜必过）

- [ ] 每个场景有机位表吗？机位数 ≤ 5 吗？
- [ ] 轴线写清楚了吗（谁在画左、谁在画右）？
- [ ] 每镜都标了 `setup` 吗？
- [ ] 同一场景里，人物左右关系有没有反过？
- [ ] 第一镜交代了空间和站位吗？
- [ ] 过肩镜头是不是都稳定的（没有大幅运镜）？
- [ ] 如果要过轴，有没有中性镜头过渡？

七条有一条不过，就重排——**机位乱的分镜，跑再多遍也是乱的。**
