# 锁脸方法论

## 一句话

**换装、跨场景 → 每段从原图 `face_ref.jpg` 重新出发。**
**同一场景的连续镜头 → 可以用尾帧接力，但必须「尾帧 + 人物参考图」双输入。**

两种做法不冲突，按场景选。

## 情况 A：换装 / 跨场景 —— 必须原图锚定

2026-10-18 实测：千问 `char` 模式，768×1344，30 步，cfg 4.0，把「原图 → 唐装 → 宋装 → 明装」连做三次换装。

| 步骤 | 输入参考图 | 脸部结果 |
|---|---|---|
| 原图 | — | 本人：圆润、有婴儿肥、自然皮肤 |
| 唐装 | 原图 | 基本是本人 ✅ |
| 宋装 | 唐装图 | 鼻梁变挺、下巴变尖，开始"网红化" |
| 明装 | 宋装图 | 眼睛变大、脸变窄，明显不是同一个人 |

**每换一次装，模型都会朝"更符合审美预设"的方向微调一次，误差单向累积。** 三步已肉眼可见，十步必然换人。

所以**换装场景的尾帧接力仍然禁止**：服装、光线、场景全变了，接力只会把上一次的美颜和偏移一起带过去。

## 情况 B：同一场景的连续镜头 —— 尾帧桥接可用

同一场景的连续几镜，最稳的做法是**把下一镜已经生成好的首帧，钉成本镜的结尾落点**
（`tail_frame` 字段，本 skill 的推荐做法，原理见 SKILL.md「尾帧桥接」一节）。

```
shot.tail_frame = "S30"   # 明确指定：S29 的最后一帧 = S30 的首帧
shot.tail_frame = "next"   # 同上，自动取下一镜
```

**原理**：两端都锚在"已经生成好、脸和景都正确"的首帧上，不会一镜一镜往下漂；
剪辑点上真的接得住（A 末帧 == B 首帧）。

> 本地 H3 路线另有一种做法：把 `face_ref.jpg` 和上一段尾帧**同时**作为双输入
> （参考图 + 尾帧），生成的第一帧能和上一段尾帧几乎完全一致 —— 脸、服装、发丝走向、
> 背景、色温全部接上。前提是**提示词里逐件锁死服装**，否则模型会按场景常识换衣服。

| 项 | 结果 |
|---|---|
| 身份（脸） | ✅ 不漂，和 face_ref 一致 |
| 场景 / 光线 | ✅ 完全接上 |
| 服装（首帧） | ✅ 一致 |
| 服装（运动中） | ⚠️ 会漂——见下 |

### 唯一的坑：运动中服装会漂

那段测试的提示词没写服装，模型按"海边休闲"的常识，把**浅色短裤换成了牛仔裤**，白衬衫也变成了敞开的度假款。

**修法**：在提示词里逐件锁死。

```text
keep exactly the same clothing as the reference frame:
white open shirt over a navy tank top, light shorts, barefoot
```

四件都要写（上装、内搭、下装、鞋），少一件模型就会自己补。

## 怎么选

| 场景 | 用哪个 |
|---|---|
| 换装、跨场景、跨时间 | **情况 A**：每段从 `face_ref.jpg` 出发 |
| 同一场景的连续对话 / 走位 / 一个动作拆成多段 | **情况 B**：尾帧 + face_ref 双输入 |
| 长镜头（>15 秒）拆段 | **情况 B**，且每段都要重述服装与轴线 |

## 正确做法：原图锚定

```
每段首帧  =  千问 char( 参考图=face_ref.jpg(原图),  提示词=该段换装 )
```

每段都只离原图一步，误差不叠加。十段的偏差都控制在同一档，彼此之间观感一致。

## face_ref 用哪张图

**直接用原图**，不要二次加工。

- 原图本身就是正脸、清晰、光线均匀 → 最优锚点
- 如果原图是侧脸/遮挡/逆光 → 换一张更正面的照片当 `face_ref.jpg`
- **不要**用三视图里的正面图当 face_ref：它是二次生成的结果，已经带了漂移

三视图的价值在别处：形象确认、客户审稿、未来做 R2V 多视图参考、转身镜头参考。

## 加强锁脸的三个手段

1. **cfg 提到 5.0**（默认 4.0）。换装属于"强指令"任务，手册建议 4.5–5.0。
2. **写"反美颜"清单**：
   ```
   不要瘦脸，不要放大眼睛，不要缩小鼻子，不要美白磨皮，
   不要去掉皮肤纹理和毛孔，不要改变肤色，保持原有的婴儿肥和下颌线
   ```
3. **逐张人工验收**：每张首帧生成后与 `face_ref.jpg` 对比。不过关就同参数重跑（模型无 seed，重跑即换随机）。

## 视频生成阶段怎么保脸

首帧图已经把人锁住了，视频阶段要做的是**别再破坏它**：

| 做法 | 原因 |
|---|---|
| 一个连续长镜头，禁止 `cut to` | 硬切会让模型在高分辨率下重建人脸，必崩 |
| 近景到"腰以上中景"为止 | 脸部占比过大时细节不够，必然糊/变形 |
| 景别变化 ≤2 倍 | 中远景直怼特写，尺度变 4–5 倍，模型撑不住 |
| 提示词不描述长相 | 文字描述会和首帧图打架，导致中途"换脸" |
| 每段结尾构图收敛 | 下一段接得上，不靠尾帧也能连贯 |

## 如果还是崩了，按这个顺序排查

1. 提示词里有没有 `cut` → 删掉
2. 有没有 `close-up` / `extreme close-up` → 改 `waist-up medium shot`
3. 有没有描述五官长相 → 删掉，只留"keep face identical as reference"
4. 景别跨度是不是过大 → 压缩到 2 倍以内
5. 以上都没问题 → 换 seed 重跑这一段（只跑这一段，不要全部重跑）
