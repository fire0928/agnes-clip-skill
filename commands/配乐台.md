---
description: 打开 Agnes Clip 配乐台（试听配乐库、逐镜调音量、重新合成）
argument-hint: "[项目目录]"
---

定位本 skill 的 `ac.py`（`~/.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py` 或项目 `.workbuddy/skills/` 下的同名文件），用 Python 3.13.12 执行：

```
<ac.py路径> music-ui --dir "<项目目录>"
```

如果项目还没配乐，先跑一次：
```
<ac.py路径> music "<项目目录>"
```

配乐台能做：
- 试听已有配乐片段
- 逐镜调音量（写回 `shot.bgm`）
- 重新合成

**两个硬规矩**（要提醒用户）：
1. 合成前必须做响度归一化，命令是 `ffmpeg -i in.mp3 -af loudnorm=I=-23:TP=-2:LRA=7 out.mp3`。
2. 目标成片响度 −16 ~ −17 LUFS。可以用 `ffmpeg -i 成片.mp4 -af ebur128=peak=true -f null -` 查，峰值不该超过 −1 dBFS。

转场有个坑要提醒：xfade 的 `duration` 不能短于一帧（24fps 下 0.04s 会让整条音轨静默截断），**硬切统一用 0.1s**。
