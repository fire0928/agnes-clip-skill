# 结尾高潮模式库（ending_modes）

> 用途：每一集**最后一镜**必须落在一个「动作高潮」上，不能只是「故事讲完了所以停」。
> 观众刷到的是短视频，最后一镜决定他点不点下一集、会不会转发。

## 一、什么叫「结尾高潮」

**反面**（平淡结尾，观众划走）：
- 两人站着对话，最后一句说完，镜头停住，片尾字幕
- 主角一个人走在路上，越来越远
- 「第二天，阳光明媚，一切都好起来了」

**正面**（有身体动作、有情绪峰值）：
- 结尾必须是**一个具体的肢体动作**，不是一句总结
- 这个动作要**回应全片的矛盾**（谁欠谁的、谁怕的、谁想要的）
- 情绪可以收，但动作必须比前面更用力

判定标准（一句话）：
> 把最后一镜的台词删掉，画面本身还能不能让人明白「这里有情绪」？
> 如果只是「两个人站着」，就是平淡结尾。

## 二、模式库

每个模式给：**适用情境 / 画面怎么演 / 首帧提示词要点 / 视频动作节奏 / 音效 / 字幕**。

### 1. `hug` —— 拥抱（和解、温暖、原谅）

| 项 | 内容 |
|---|---|
| 适用 | 吵完架之后的和解、亲人的重逢、道歉被接受 |
| 画面 | 两人从分开到贴近，一人主动张开双臂，另一人愣住半拍再扑进怀里，**紧紧抱住**、肩膀发抖 |
| 首帧 | 两人正面相对，中间留半步空隙，拥抱前的瞬间；手还垂着 |
| 动作节奏 | 0-2s 走近；2-4s 张开双臂；4-6s 抱住+对方回抱；6-8s 下巴抵在对方肩上，眼睛闭上 |
| 音效 | 衣料摩擦声（soft cloth / rustle）、一声呼气 |
| 字幕 | 台词放在拥抱前 1 秒，别压在拥抱上（画面已经够满） |

> 本集（ep03）用的是这个模式。

### 2. `slap` —— 挨打（冲突、爽感、黑色幽默）

- 画面：巴掌落在脸上（**用侧脸/背脸表达力度，不拍正面血腥**），头被打偏，耳根发红
- 动作节奏：手抬起 → 落 → 头偏 → 愣 1 拍 → 委屈
- 音效：一记干脆的 `slap`（比 `tick` 响），观众要有「脆」的感觉
- 用法：**要么真打（喜剧/爽剧），要么差一点没打着（更安全）**

### 3. `ear_pinch` —— 揪耳朵（家庭、训诫、搞笑）

- 画面：一只手揪住另一只的耳朵往上提，被揪的脚跟离地、眼睛挤成一条缝、双手护耳朵
- 动作节奏：揪 → 提 → 疼得缩脖子 → 求饶
- 音效：短促的 `tick` + 一声「哎哟」的痛呼（可用 VAD 里的真实人声）

### 4. `carry_log` —— 扛木头/扛大件（硬汉、承担、力挽狂澜）

- 画面：一根粗木头/大箱被扛上肩，脚步沉，地面震一下，扛的人被压得矮一截
- 动作节奏：弯腰 → 扛起 → 站直（爆发点）→ 迈步走出去
- 音效：木头摩擦、脚步重击地面
- 适合：主角在外人面前显本事、把东西抢回来

### 5. `sweep` —— 扫地/收拾残局（收尾、回归日常、治愈）

- 画面：主角默默扫地把打翻的碗收起来，扫到一半停住，深吸一口气，继续扫
- 动作节奏：扫 → 停 → 一个特写小物件（碗/围裙/工牌）→ 继续扫
- 音效：扫帚沙沙、瓷碗轻碰
- 用法：**平静但有重量**的结尾，适合「和解之后的生活继续」

### 6. `spit_take` —— 被泼/被浇（狼狈、笑点、报应）

- 画面：一盆水从头顶浇下，浑身湿透贴在头上，愣住，然后抹一把脸
- 音效：水声（pour / splash）
- 用法：喜剧收尾，必须接一句台词抖包袱

### 7. `wave_back` —— 回头挥手（离别、远行、"下次见"）

- 画面：主角走到街口/桥头，停下，**回头**，举起手大幅挥动，笑着
- 动作节奏：走出几步 → 停 → 回头 → 大幅挥手 → 转身走远
- 音效：脚步、风、一声远处的喊
- 用法：开放式结尾，适合连载（下一集钩子）

### 8. `light_up` —— 灯亮/点亮（希望、开始、格局打开）

- 画面：一间黑着的屋子，最后一镜灯"啪"地亮起，人影在暖光里出现
- 音效：一声开关 + 音乐起
- 用法：温情转希望，适合"新的开始"型结尾

### 9. `bow_apology` —— 鞠躬道歉（谦卑、臣服、真心）

- 画面：深深一躬，头低到底，双手垂在身前；对方伸手扶起
- 用法：代替 `hug` 的和解方式，更含蓄

### 10. `phone_pickup` —— 拿起手机/接到电话（悬念、钩子）

- 画面：手机在桌上震，屏幕亮起，主角的手伸进画面拿起来，屏幕光照在脸上
- 用法：**连载钩子**，下一集的引子

## 三、怎么用

1. 写剧本时先定**模式**，再写最后一镜的画面。
2. 在镜头表里给最后一镜标 `"ending_mode": "<模式名>"`。
3. 最后一镜：
   - `intensity` 应是全片**最高或接近最高**（≥ +3）
   - `purpose` 标 `"高潮"`
   - 台词要**短**（≤ 10 字更好），动作承担主要情绪
   - 这一镜要有 **1–2 个音效**，不能只有背景乐
4. `ac.py check` 会自动检查：末镜有没有 `ending_mode`、`intensity` 是否够高、是不是只有台词没有动作。

## 四、常见错误

- ❌ 末镜是「两人站着说话」→ 平淡
- ❌ 末镜情绪是「回落」（前面很激动，最后突然平静）→ 除非刻意做「暴风雨后的宁静」，否则观众会觉得没劲
- ❌ 末镜时长太短（< 4 秒）→ 动作没演完就被切断
- ❌ 末镜没有音效 → 干巴巴
