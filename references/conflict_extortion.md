# 讹人冲突的化解套路

> 来源：ep05《清炒折耳根》——用户要求「把一些讹人的社会现象也要包含进来」，
> 且「化解的方式要幽默一点儿，实在不行就撒丫子跑吧」。

---

## 一、为什么这类冲突特别适合美食号

**别的行业吵不出结果，一盘菜能。**

主角不需要讲道理、不需要报警、不需要打一架——
**把菜端过去让讹人的自己尝**，冲突就消解了。

这是美食号特有的优势：它把「谁有理」的问题，换成了「东西好不好吃」的问题。

---

## 二、标准五步（ep05 实测）

| 步 | 谁 | 做什么 | 为什么有效 |
|---|---|---|---|
| **1. 冲突爆发** | 找茬的人 | 蛮不讲理：「谁让你们挖的！赔钱！」 | 情绪压到谷底（-4），观众站主角 |
| **2. 问塌前提** | 主角的搭档 | **一句话问他的立论前提**：「您这折耳根，一斤卖几个钱？」 | 讹人的**理由自己塌了**——这东西根本不值钱 |
| **3. 用菜说话** | 主角 | 不吵不闹，**把刚做好的那盘端过去**：「您尝尝，值不值这个价」 | 把「你讹我」变成「你尝尝你自家的东西」 |
| **4. 内部人拆台** | 找茬的人的自己人 | 当众戳穿：「你晓不晓得根本没人要！」 | **比外人讲道理解气十倍** |
| **5. 自己打自己脸** | 找茬的人 | 尝完，眼眶红了：「这、这真是我家的味道！」 | 讹人的**主角自己被打服**，比主角赢更彻底 |

**可选第 6 步（喜剧收束）**：一窝蜂端锅跑走 —— 狗老弟叼着盘子跑、
松鼠钻草丛。节奏带起来，别让场面僵在那儿。

**可选第 7 步（落点）**：野炊宴摆开，**找茬的也坐上桌**。
社会现象类剧情的落点不是「赢」，是「和解」。

## 三、关键设计原则

### ① 找茬的人不能是纯恶人
ep05 的老乡是「自己也知道理亏、但嘴上不肯认」的老实农民。
这样他被折耳根征服才有看点——**纯恶人被感化是套路，普通人被说服才是真事**。

### ② 内部人拆台 > 外人讲道理
这是本套路最解气的一招。
观众看两个陌生人吵架只会烦，看**一家人自己拆台**会笑。

### ③ 化解要靠「东西」，不靠「话」
主角说再多道理都不行，**把菜端过去**就解决了。
所以做菜段必须够好——这一段的说服力是整个冲突段的地基。

### ④ 找茬的人要有「自己的东西」
他索赔得有一样东西是他自己的。折耳根地、鲊广椒地、腊肉摊……
**这块地就是矛盾的根**，挖根这件事本身让他有理由发作。

## 四、台词模板

```
冲突爆发：
  「谁让你们动的！赔钱！」        ← 6-8 字，不解释，先炸

问塌前提（搭档）：
  「大爷，您这<东西>，一斤卖几个钱？」   ← 问句，不带情绪
  「这个价，值几个钱？」

用菜说话（主角）：
  「您尝尝，值不值这个价。」     ← 8 字以内，平视，不卑不亢

内部人拆台（自己人）：
  「你晓不晓得这东西根本没人要！」  ← 6-9 字，直白

自己打脸（找茬的）：
  「……这、这真是我家的味道！」    ← 语气要软，尾音上扬 = 被征服
```

**注意**：找茬的**第一次开口要短**（爆发），**第二次开口要软**（被征服）。
这个反差就是笑点。

## 五、这类冲突的镜头安排

| 镜 | 拍法 | 注意 |
|---|---|---|
| 冲突爆发 | 中景对峙 | **反派别跟主角贴太近**（模型容易串脸） |
| 问塌前提 | 主角搭档的**特写或近景** | 焦点在提问的人，不在反派 |
| 用菜说话 | **菜的大特写** + 反派的反应镜（分开拍） | 菜要好看，反派的脸单独拍 |
| 内部人拆台 | 双人镜（自己人 + 反派） | 只有 2 人，不容易串 |
| 自己打脸 | **反派的特写** | 表情变化是这一段的全部价值 |
| 一窝蜂跑走 | 大全景 | 喜剧节奏 |

🔴 **别把反派和主角放同一镜里**（ep04 ep05 都验证过：同框会串脸/丢特征）。
对峙用「A 的反应镜 + B 的反应镜」两镜剪，比一个双人镜稳。

## 六、验收清单

- [ ] 找茬的人有**自己的东西**吗（不然索赔没依据）？
- [ ] 他是不是**纯恶人**？（纯恶人被感化很套路）
- [ ] 有**内部人拆台**吗？（没有的话化解会显得主角自说自话）
- [ ] 化解靠的是**菜**还是靠嘴？（必须是菜）
- [ ] 找茬的人前后**语气有反差**吗？（爆发 → 软）
- [ ] 反派和主角**没有同框**吗？
- [ ] 落点是「赢」还是「和解」？（社会现象题材选和解）
- [ ] 有喜剧泄气阀吗（一窝蜂跑走）？
