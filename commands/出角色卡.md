在用户机器上定位本 skill 的 `ac.py`（优先 `~/.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py`，其次当前项目 `.workbuddy/skills/agnes-clip-平哥分享版/scripts/ac.py`，兼容目录名带"分享版"或英文名的情况），然后：

1. 用 WorkBuddy 自带的 Python 3.13.12 运行（**不要用 3.14.3**，那个环境已损坏）：
   `<python3.13.12> <ac.py路径> char-gen "$ARGUMENTS"`
2. 跑完后**打开 `assets/characters/<角色名>/char_card.jpg` 给用户看**——设定卡是给人过目造型的，必须肉眼验收。
3. 同时说一句：角度图已自动裁到 `views/`，首帧会按机位自动取。

**这个命令产出三个文件，用途完全不同**：

| 文件 | 干什么用 |
|---|---|
| `face_ref.jpg` | 干净正脸半身照，**首帧锁脸锚点**，全片每镜都拿它当参考 |
| `char_card.jpg` | 多格设定稿（大头 + 三视图 + 表情行 + 细节特写），**给人看造型** |
| `views/{front,side,back}.jpg` | 从设定卡裁出的角度图，首帧按机位自动取 |

**关键纪律要提醒用户**：`char_card.jpg` 绝不能拿去当首帧参考图——它是多格排版，
当参考图会把分格线和隔壁格的人一起喂进首帧，单镜头构图直接崩。只用 `face_ref.jpg`。

**版式**（`--card-style`）：
- `sheets`（默认）：左大头 + 中间三视图（正/侧/背）+ 底部四表情 + 右侧细节格
- `turnaround`：左大头 + 上排四个角度 + 表情行 + 右侧全身站姿

**出图通道**（`--channel`）：`agnes` 快、额度够；`gpt-image` 分格更直、透视更准、服装细节更细。
不给就跟随配置。**正脸和设定卡必须同通道**（换通道等于换人），代码已强制锁定。

**验收清单**（挨个跟用户确认）：
1. 设定卡每一格是不是同一个人？（脸型、发型、服装要对得上）
2. 表情有没有区分度？（垂眼、生气、微笑要明显不同）
3. 年龄和气质贴不贴人设？

设定卡不对就改描述重跑，别将就——这张错了后面所有镜头都错。
